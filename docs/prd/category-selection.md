> Prompt 源：`[src/scripts/seed-prompts.ts](../../src/scripts/seed-prompts.ts)`。回填时在 prompt 后追加  `as of {periodStartDate}`，不改 seed 正文。
> exclude 机制同现网 `excludedCategories`（只排除列出的品类）；同品牌允许多品类上榜。干跑可追加 exclude。
> phase-4 P5：代码 / seed / exclude / 首页·排行入口已接线；**公开榜数据仍待** `seed` → `backfill:categories --execute` → launch-gate → publish。VPN / Password prompt 避免写飘：`best privacy tools`、`best security apps`、`best authenticators`。

## 一票否决（任一不过则淘汰）

1. AI 确实经常被问：该品类在主流 AI 引擎里是高频推荐/比较题，不是偶发问题
2. 地域性弱：全球或主要英语市场通用，避开本地强绑定品类
3. 实体边界清晰：Top 20 多为同级可比较对象，不做大杂烩品类
4. 合规风险可控：避开处方药、诊断、赌博、成人等高风险场景

## 高权重（决定值不值得做）

1. 有人看榜：存在 `best X` / `which X` / `X alternatives` 等真实搜索意图
2. 有人持续关注：竞争会随周期变化，不是一年看一次
3. 品牌之间存在竞争：同级品牌抢同一推荐位，不是垄断或无竞品品类
4. 品牌会因为 AI 推荐获得收入：被推荐能带来注册、购买或转化，不只是虚荣曝光
5. 有付费买家：品牌 / 市场 / 增长团队会为「AI 是否推荐我」付钱
6. 大厂不锁死榜单：Top 5 不该长期被 1–2 个垄断品牌占满

## 中权重（影响可运营性与质量）

1. 品牌密度够：干跑后至少约 30 个有效候选品牌
2. 广告 / 推荐预算厚：该品类本就投入 SEO、affiliate、内容种草
3. 周期波动有意义：新品、偏好变化会让榜动起来
4. 审核负担可控：别名与脏实体不会把 Review Queue 打爆；归并规则可预先定义
5. 与现有品类重叠可控：扩覆盖面，不把同一批品牌再拆一遍

## 低权重（加分，不单独决定）

1. 英文 prompt 可直接问：以全球英文市场为主
2. 截图 / 传播友好：大众认识的品牌名，周期看点与象限图可传播

## 判定

- 一票否决项全部通过，否则直接淘汰
- 高权重 6 项中至少过 4 项，才进候选
- 中权重用于排序与排期；低权重同分时作 tie-break
