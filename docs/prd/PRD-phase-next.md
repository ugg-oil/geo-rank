- 引擎推荐差异分析
- X / LinkedIn / Reddit / HN 发布素材（预览 + 人工审核）

## 品牌对比

- 同一品类对比 2–3 个品牌，URL 可分享
- Rank 历史折线、引擎分项柱状图、Mention Frequency 柱状图
- 缺失数据展示 `No data`
- 初期免费；后续付费能力：保存竞品组、自动提醒、更长历史、CSV / PDF 导出
