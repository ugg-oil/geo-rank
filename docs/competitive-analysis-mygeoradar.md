## 三、商业模式对比

### GEO Radar（我方）
- **当前**：零商业化，全部数据免费公开；Phase 2 仅 `Track Your Brand` CTA 占位（不接支付）
- **规划**（phase-next）：品牌监测订阅、GEO Audit、付费报告、团队功能
- **优势**：独家周度数据（3 引擎 × 5 品类 × 8 prompt = 120 次/周）构成数据壁垒
- **风险**：变现路径完全未验证，无任何收入信号

### MyGeoRadar（竞品）
- **漏斗**：免费扫描（免注册）→ 展示 pass/fail 问题 → 引导购买 Full Report
- **定价**：Full Report $29.99 一次性；GEO Playbook $27；明确反订阅定位（"不是 $99/月"）
- **卖点**：30 天复扫 + 30 天无理由退款 + Stripe 支付
- **转化机制**：免费扫描制造"认知差距"（"原来我只有 30 分"）→ 低客单价降低决策门槛
- **风险**：一次性收入模型，复购场景弱

**结论**：竞品已有完整的免费→付费转化链路和定价验证；我方目前只有免费数据展示，无付费环节。

## 四、SEO 与流量策略对比

| 维度 | GEO Radar | MyGeoRadar |
|------|-----------|------------|
| 核心流量页面 | 5 个品类榜 + 历史周 + 方法论 | 首页（工具） + 5 个平台指南 + 行业页 + 城市页 |
| 长尾词覆盖 | "AI visibility rankings"、品类词 | "GEO for WordPress/Shopify"、"rank in ChatGPT"、"llms.txt"、行业×城市组合 |
| 工具型流量 | 无主动工具 | 免费扫描器（天然吸引自然流量 + 外链） |
| 结构化数据 | JSON-LD（WebSite/Org/Breadcrumb） | 基础 metadata + OG/Twitter |
| 索引策略 | 品类页可索引；历史周与 Brand Page noindex | 全站 index,follow |
| 外链素材 | 榜单数据（品牌想看自己排名） | 平台指南 + 数据统计（SparkToro/Datos 引用） |

**竞品关键优势**：平台指南（WordPress/Shopify/Webflow/Wix/Squarespace）+ 行业/城市落地页构成了多层长尾内容矩阵，且每个指南都内链回免费扫描器，形成"内容→工具→转化"闭环。我方目前内容页面较少，且把最有 SEO 价值的 Brand Page 设为 noindex。

## 五、用户获取与转化路径

### GEO Radar
```
用户访问 → 浏览免费排名榜单 → 查看品牌详情 → （未来）Track Your Brand CTA
                                                    ↓
                                           （尚未实现，无转化）
```

### MyGeoRadar
```
用户访问（自然流量/指南页/行业页）→ 免费扫描（免注册）→ 展示问题清单
        → 平台指南（自助修复）或 Full Report $29.99（完整修复清单）
```

**关键洞察**：竞品转化路径短、零摩擦（免注册扫描）、低客单价，且把付费理由（"告诉你先修什么"）讲得非常具体。我方数据资产更强，但缺少"用户主动行动"的入口和付费抓手。

## 六、优劣势总结

### GEO Radar 优势
1. **独家数据壁垒**：每周真实采集 3 引擎回答，产出品牌提及数据，竞品无法复制
2. **排名权威性**：透明评分公式 + 公开方法论，可成为行业"排名标准"（Nielsen 模式）
3. **历史追踪能力**：周级对比、Δ 变化、Biggest Movers，竞品完全没有
4. **品牌级洞察**：Brand Page 展示跨品类可见度，B2B/SaaS 场景价值高
5. **目标市场差异化**：面向软件/SaaS 的 B2B 榜单 vs 竞品面向本地商家的技术扫描，无直接重叠

### GEO Radar 劣势
1. **零变现**：无收入、无付费验证，商业模型停留在规划
2. **缺工具属性**：用户只能"看"榜单，不能"输入自己的品牌"获得即时反馈
3. **缺 actionable 输出**：告诉用户排名，但不告诉"如何提升"（无修复建议/指南）
4. **SEO 内容单薄**：页面数量远少于竞品，Brand Page 还设 noindex
5. **无社交证明**：无客户案例、无创始人故事、无 Twitter 等外部分发

### MyGeoRadar 优势
1. **变现链路成熟**：免费→付费转化已验证，定价、退款、复扫闭环完整
2. **零摩擦体验**：免注册、30 秒出结果，传播性极强
3. **Actionable**：pass/fail 清单 + 平台指南 + 优先修复顺序，用户知道"下一步做什么"
4. **内容生态**：指南 + 行业页 + 城市页构成 SEO 长尾矩阵
5. **信任建设**：创始人实名背书、署名客户评价、数据引用（SparkToro）
6. **反订阅定位**：$29.99 一次性 vs 竞品 $99/月，决策成本低

### MyGeoRadar 劣势
1. **无真实排名数据**：基于技术信号推断 AI 可见度，未直接采集 AI 回答
2. **无历史趋势**：只有单次扫描 + 30 天复扫，无长期追踪
3. **一次性收入**：无订阅/复购模型，LTV 受限
4. **B2B 深度不足**：面向本地商家，对 SaaS/产品团队的品牌级分析缺乏
5. **技术门槛低**：检查项（Schema/NAP/robots.txt）通用 SEO 工具也能覆盖，差异化不足

## 七、战略建议

### 短期（Phase 2 完成前）

1. **补上"输入品牌"工具**：增加品牌搜索框（输入品牌名 → 展示其在各品类可见度），把被动榜单变成主动工具，对齐竞品的工具属性
2. **启动邮箱收集**：`Track Your Brand` CTA 先接邮箱捕获（不用支付），验证需求、积累列表
3. **发布"如何提升 AI 可见度"指南**：参考竞品 guides 模式，但差异化定位为"品牌级 GEO 策略"（内容/权威度/引用建设），而非技术修复
4. **开放 Brand Page 索引**：评估将满足数据门槛（如连续 4 周）的品牌页放开 index，抢占品牌词搜索流量

### 中期（Phase 2 完成后）

5. **设计付费阶梯**：
   ```
   免费：当前周排名 + 品牌搜索
   付费 $29–$49/次：品牌 GEO 报告（跨引擎推荐差异 + 竞品对比 + 提升建议）
   订阅 $49–$99/月：持续监测 + 周报通知 + 历史趋势
   ```
6. **内容矩阵扩展**：按品类 × 引擎写"AI 推荐差异分析"文章，复用独家数据产出可索引内容
7. **信任建设**：公开创始人/团队背景、方法论验证数据、用户案例（早期可找种子用户换反馈）

### 长期

8. **开放数据 API**：让第三方消费排名数据，建立 GEO 数据标准与生态
9. **双向覆盖**：在保持产品级榜单的同时，评估为品牌提供"网站级 AI 可见度"轻量检查（借鉴竞品技术信号检查，但输出与自身排名数据打通）

## 八、核心竞争力定位

```
MyGeoRadar 护城河：免费工具的病毒传播 + 平台指南内容生态 + 已验证的 $29.99 变现
GEO Radar 护城河：独家真实 AI 回答数据 + 历史趋势追踪 + 品牌级 B2B 洞察
```

**两者本质是互补而非直接竞争**：MyGeoRadar 回答"我的网站技术层面是否被 AI 理解"（网站级、技术信号、本地商家）；GEO Radar 回答"哪些产品被 AI 推荐"（品牌级、真实回答、SaaS/B2B）。

**GEO Radar 的差异化机会**：成为 AI 推荐领域的权威排名来源（类似 G2/Capterra 之于软件评测，或 Nielsen 之于收视率）。这个定位 MyGeoRadar 完全不具备，且数据采集能力是真实壁垒。

**最大风险**：若我方持续零变现、无主动工具、无内容分发，MyGeoRadar 这类低门槛工具会先占领"GEO"这一关键词的搜索心智和付费用户，我方将沦为"免费数据源"而非商业产品。
